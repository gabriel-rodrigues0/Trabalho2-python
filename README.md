# Adivinha Personagem: Stranger Things 4

Jogo de perguntas no terminal, em Python, que descobre em qual personagem de Stranger Things 4 você está pensando.

<img src="https://img.shields.io/badge/Python-0D0D0D?style=for-the-badge&logo=python&logoColor=FF1A2B" alt="Python" />

</div>

## Sobre

Trabalho de programação do ensino médio técnico em Informática (2023). O programa faz perguntas de sim ou não e, por uma árvore de decisão com `if`/`elif`/`else`, chega ao personagem.

## Funcionalidades

- Perguntas encadeadas sobre sexo, papel no grupo, idade e outras características
- 16 personagens possíveis, entre eles Eleven, Max, Dustin, Steve, Joyce e Hopper
- As respostas são comparadas com texto exato, em minúsculas (ex.: `sim`, `feminino`, `adolescente`)

## Tecnologias

- Python 3

## Como executar

```
python TB.py
```
